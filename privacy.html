school-rag プライバシーポリシー

制定日:2026年10月6日

1. 対象

本アプリは運営者本人とその家族のみが利用する個人用アプリです。Google アカウントによる認可は運営者本人のみが行います。

2. 取得する情報

Google の gmail.readonly 権限(読み取り専用)を使い、運営者の Gmail のうち、指定した1つのラベルが付いたメールの件名・送信者・受信日時・本文だけを取得します。それ以外のメール、連絡先、カレンダーなどの情報は取得しません。メールの送信・変更・削除は行いません。添付ファイルは取得しません。

3. 利用目的

取得したメールから行事の予定(日付・持ち物など)を取り出して保存し、家族の質問に、元メールを示しながら答えるためにのみ使います。広告、販売、それ以外の目的には使いません。

4. 第三者への提供

予定の抽出と回答の作成のため、必要な範囲のメール本文または抜粋を、AI サービスである Anthropic, PBC の API に送信します。これ以外の第三者には提供しません。

5. 保存と削除

取得したデータは運営者が管理する環境に保存し、受信から12か月を過ぎたものは自動で削除します。Google の認可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。
